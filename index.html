React Hooks Cheat Sheet

useState

Manages state within functional components. Allows you to declare a state variable and a function to update it. React will re-render the component when the state changes.

const [count, setCount] = useState(0);

// In your component's return:
// <div>
//   <p>You clicked {count} times</p>
//   <button onClick={() => setCount(count + 1)}>
//     Click me
//   </button>
// </div>

useEffect

Performs side effects in functional components. It runs after every render by default, but you can control when it runs by providing a dependency array. Common uses include data fetching, subscriptions, or manually changing the DOM.

// Assuming 'count' is a state variable
useEffect(() => {
  document.title = `You clicked ${count} times`;

  // Cleanup function (optional)
  return () => {
    // This runs when the component unmounts or before the effect runs again
    // console.log('Effect cleanup');
  };
}, [count]); // Only re-run the effect if 'count' changes

useContext

Provides a way to pass data through the component tree without having to pass props down manually at every level. Useful for sharing global data like themes, user info, etc.

// 1. Create a Context
// MyContext.js
// import React from 'react';

// 2. Provide the Context value
// App.js (or a parent component)

// ...
// <MyContext.Provider value="some value">
//   <ChildComponent />
// </MyContext.Provider>

// 3. Consume the Context value

useReducer

An alternative to useState for managing more complex state logic, especially when state transitions depend on the previous state or involve multiple sub-values. It uses a reducer function to update state based on dispatched actions.

const initialState = { count: 0 };

function reducer(state, action) {
  switch (action.type) {
    case 'increment':
      return { count: state.count + 1 };
    case 'decrement':
      return { count: state.count - 1 };
    default:
      throw new Error();
  }
}

// In your component:
// const [state, dispatch] = useReducer(reducer, initialState);
//
// <div>
//   Count: {state.count}
//   <button onClick={() => dispatch({ type: 'decrement' })}>-</button>
//   <button onClick={() => dispatch({ type: 'increment' })}>+</button>
// </div>

useCallback

Returns a memoized callback function. This is useful when passing callbacks to optimized child components that rely on reference equality to prevent unnecessary renders. The callback is only recreated if one of its dependencies changes.

// import React, { useState, useCallback } from 'react';
// import ChildComponent from './ChildComponent';

//   // Without useCallback, handleClick would be a new function on every render

//     // Potentially use 'count' or other dependencies here
//   }, []); // Dependencies array: if empty, created once

//   return (

//       <button onClick={() => setCount(count + 1)}>Increment Count</button>

useMemo

Returns a memoized value. It recomputes the memoized value only when one of the dependencies has changed. This optimization helps to avoid expensive calculations on every render.

useRef

Returns a mutable ref object whose `.current` property is initialized to the passed argument (initialValue). It can be used to access a DOM element directly or to keep a mutable value that does not cause a re-render when it changes.
